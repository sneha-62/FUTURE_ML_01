# FUTURE_ML_01

## Task 1 - Sales & Demand Forecasting Using Linear Regression

### 📌 Project Overview
This project builds a forecasting model to predict future sales using historical Superstore dataset data.

### 🔧 Steps Performed
- Data Cleaning
- Monthly Sales Aggregation
- Time-based Analysis
- Linear Regression Model
- Model Evaluation using MAE
- Actual vs Predicted Visualization

### 📊 Business Interpretation
The model predicts future monthly sales trends.  
This helps businesses in:
- Inventory planning
- Budget forecasting
- Identifying high-demand periods
- Better decision making

### 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
